# Security Policy

At [Agileware](https://agileware.com.au), we take the security of our open-source software and managed WordPress plugins seriously. If you believe you have found a security vulnerability in this repository, we appreciate your help in disclosing it to us responsibly.

## Supported Versions

We actively maintain and provide security patches for the latest major versions of our plugins. Please ensure you are running an updated release before submitting a report.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.32   | :x:                |

*Note: Critical security patches are released for the latest stable tagged version available on GitHub.*

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, pull requests, or community forums.**

To report a vulnerability, please follow these steps:

1. **Email Us:** Send an email directly to **[security@agileware.com.au](mailto:security@agileware.com.au)**.
2. **Provide Details:** Include as much detail as possible to help us reproduce and address the issue, such as:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept code/screenshots.
   - The version of the plugin, WordPress, and CiviCRM environment affected.
   - Potential impact of the issue if exploited.

For general inquiry or non-security support, please visit our website at [agileware.com.au/contact](https://agileware.com.au/contact).

### What to Expect

* **Acknowledgement:** We aim to acknowledge receipt of your report within **2 business days**.
* **Assessment & Updates:** Our team will investigate the report to confirm the vulnerability. We will keep you updated on our progress toward a fix at least once every **5 business days**.
* **Resolution:** If accepted, we will develop a patch and issue a new release. We will notify you once the fix has been published.
* **Public Disclosure:** We request that you maintain confidentiality until we have issued an update to protect affected sites. Once resolved, we are happy to acknowledge your contribution in our release notes (unless you prefer to remain anonymous).

Thank you for helping keep Agileware products and the WordPress/CiviCRM community safe!
